# Research Digest Agent

Researches the topics in [topics.toml](./topics.toml), remembers what it has already reported, and writes a digest of what's new.

Built block by block — see [../CURRICULUM.md](../CURRICULUM.md).

## Run (from repo root)

```bash
python -m capstone.digest.config   # sanity check
```
